# Helicone Documentation

## How it works

When you route requests through the Helicone AI Gateway, every call is intercepted, logged, and forwarded to your LLM provider. The response returns to your application as normal. From your code's perspective, nothing changes except the `baseURL`.

```text
Your App  →  Helicone AI Gateway  →  LLM Provider (OpenAI, Anthropic, etc.)
                     ↓
              Dashboard Logs
```
